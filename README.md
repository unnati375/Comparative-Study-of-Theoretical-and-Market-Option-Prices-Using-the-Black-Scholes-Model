# **Comparative Study of Theoretical and Market Option Prices Using the Black–Scholes Model**
# **Abstract**
To apply and evaluate the Black-Scholes option pricing model using historical data of a stock and its
associated call option contract expiring on 31st July. The project focuses on estimating key parame
ters—especially market volatility—and comparing the Black-Scholes theoretical price with the market
settled price to assess pricing accuracy.
